================================================================================
  1. VISÃO GERAL E OBJETIVOS
================================================================================

O projeto Estrato é uma "fábrica de portais" (Portal Factory) de notícias
WordPress, projetada para operar uma rede multi-vertical sob o domínio
estrato.cc e subdomínios (mente, lifestyle, science, agro, etc.).

Objetivos principais:
  - Publicação automatizada via pipeline Python no VPS Victor
  - Layout editorial inspirado no padrão G1/Globo (header em camadas, trilho
    horizontal de editorias, manchete + bloco "Agora" + feed por categoria)
  - SEO técnico, schema, Google News, AEO/GEO (llms.txt, IndexNow)
  - EEAT/YMYL para conteúdo financeiro e de saúde
  - Anti-regressão automatizada (robots, sitemap, schema, nav, mobile)
  - Deploy reproduzível por YAML (portals/*.yaml) + scripts Victor

Stack principal:
  - WordPress 6.x + PHP 8.3-FPM + nginx
  - Tema PressGrid 2.5 (produção)
  - 3 plugins próprios (portal-bootstrap, rss-bootstrap, publisher-bridge)
  - Cloudflare (DNS + proxy SSL Full)
  - Yoast SEO, Contact Form 7

  3. ARQUITETURA DO SISTEMA
================================================================================

3.1 Diagrama lógico (texto)

  [Fontes RSS / Web] ──► [Pipeline Victor - Python]
                              │
                              │ scout (1h)
                              │ curator (5min)
                              │ writer (5min)
                              │ publisher (5min)
                              │ linker (5min)
                              ▼
                    wp_bridge.py / REST API
                              │
                              ▼
              estrato-publisher-bridge (WordPress)
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
     estrato-rss-bootstrap   posts WP    estrato-portal-bootstrap
     (complementar RSS)                    (render, SEO, nav, home)
              │                               │
              └───────────────┬───────────────┘
                              ▼
                    Tema PressGrid 2.5
                              ▼
                    nginx + PHP-FPM + Cloudflare
                              ▼
                         Usuário final

3.2 Camadas de responsabilidade

  | Camada          | Componente                    | Função                    |
  |-----------------|-------------------------------|---------------------------|
  | Edge            | Cloudflare                    | DNS, CDN, SSL, WAF        |
  | Web             | nginx + PHP 8.3-FPM           | Servir WordPress          |
  | CMS             | WordPress + PressGrid         | Tema base, widgets        |
  | Plugins Estrato | portal-bootstrap              | Factory, UI G1, SEO       |
  | Plugins Estrato | publisher-bridge              | API publicação            |
  | Plugins Estrato | rss-bootstrap                 | Feeds RSS BR              |
  | Conteúdo        | Pipeline Victor (Python)      | IA + curadoria + publish  |
  | Config          | portals/*.yaml                | Declarativo por portal    |
  | Ops             | scripts/victor/*              | Deploy, gates, setup      |

3.3 Fluxo de publicação (pipeline_primary)

  Modo padrão dos portais em produção: pipeline_primary
    - Pipeline Victor é a fonte principal de artigos
    - RSS complementar: poucos itens/hora (ex.: 2/feed, máx 15/run)
    - Imagens: originais da matéria (og:image, conteúdo); sem stock Unsplash
    - Dedup: external_id no bridge
    - Thumbnails: sideload + cron backfill hourly

4.2 estrato-publisher-bridge — v1.7.1
--------------------------------------------------------------------------------

Arquivo principal : estrato-publisher-bridge/estrato-publisher-bridge.php
Constante versão  : ESTRATO_BRIDGE_VERSION = '1.7.0' (header plugin 1.7.1)
Secret option     : estrato_bridge_secret

Endpoints REST:

  POST /wp-json/estrato/v1/publish
  POST /wp-json/estrato/v1/taxonomy-sync

Autenticação:
  Header: X-Estrato-Secret: <valor de estrato_bridge_secret>

Payload publish (exemplo):

  {
    "title": "Título da notícia",
    "content": "<p>Corpo HTML</p>",
    "category": "economia",
    "source_url": "https://...",
    "source_name": "G1",
    "external_id": "unique-id-for-dedup"
  }

Funcionalidades:
  - Sideload imagem destacada da URL original
  - Rejeição de imagens stock
  - Dedup por external_id
  - Cron hourly backfill thumbnails (estrato_thumbnail_backfill_event)
  - Unpublish posts sem imagem original
  - Meta: _estrato_original_image_url, _estrato_skip_reason
